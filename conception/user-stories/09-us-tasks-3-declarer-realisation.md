**Description (Notion)**  
En tant qu'utilisateur connecté, je peux déclarer la réalisation de tâches AFIN de confirmer et utiliser pour tracking le projet dans le foyer.

# Intitulé

En tant qu utilisateur dans un groupe je souhaite déclarer une action afin de participer à l’effort de groupe.

# Etapes

- Dans l’accueil d’un groupe j’observe des labels et des tâches
- Je peux sélectionner un label pour filtrer les tâches visibles
- Au tap sur une tâche, le panneau de tâche s’ouvre par dessus celui des tâches et laisse le monstre visible
- Je peux déclarer une action :
  - Pour moi
  - Pour quelqu’un d’autre
- Je peux aussi config la tâche à l’aide d’une petite icone de rouage
- Quand je déclare l’action, je nourris le monstre et profite de l’animation dans le panneau inférieur

# Cas limites

- Impossible de spam une tâche plus de 3 fois
