# Intitulé

En tant qu utilisateur dans un groupe je souhaite créer une tâches afin de pouvoir déclarer plus tard quand je fais quelque chose pour le groupe.

# Etapes

- Une fois connecté dans un groupe
- je clic sur le “+”
- Je sélectionne “Task”
- Une bottom sheet s’ouvre
  - Nom
  - Label
  - Jauge de quantité (chiant / pas chiant ou calories …? selon le concept du monstre)
  - Fréquence parmi une sélection de choix
  - J’observe visuellement le rendu de l’icône de la tâches
- A validation, la tâches apparait dans la liste des tâches

# Cas limites

- Pas de tâche avec le même nom
- Quantité limite de poid / dureté de tâche (slider)
