# Intitulé

En tant qu utilisateur dans un groupe je souhaite déclarer des label afin de catégoriser et retrouver plus facilement mes tâches.

# Etapes

- Une fois connecté dans un groupe
- je clic sur le “+”
- Je sélectionne “Label”
- une bottomsheet me permet de configurer visuellement mon label
  - Nom
  - Couleur
- A validation, le label apparait dans la liste des label en scroll horizontal

# Cas limites

- Pas deux labels du même nom
