**Description (Notion)**  
En tant qu'utilisateur hors groupe, je veux rejoindre un groupe ou en créer un AFIN de pouvoir mettre en place ses tâches et visualiser ma progression selon le sein de ce groupe.

# Intitulé

En tant qu utilisateur inscrit, je souhaite faire parti d’un groupe afin de me retrouver avec mes amis ou ma famille dans l’application.

# Etapes

**Un groupe n’existe pas**

- À la fin de l’inscription, je choisi “créer un groupe”
- On me demande le nom du groupe
- On me propose d’inviter des membres dans le groupe à l’aide de mes contacts grâce à un deeplink à partager par sms ou whatsapp
- Je suis redirigé dans l’accueil groupe
- Dans les paramètres du groupe, je peux copier le lien d’invitation deeplink ou le code secret du groupe

**Un groupe existe**

- Je peux cliquer sur le deeplink partagé par le créateur du groupe
  - Le deeplink contient le code secret, pas besoin de faire quelque chose d’autre je suis redirigé vers la page d’accueil du groupe
- Je peux faire une recherche textuelle pour retrouver le groupe par son nom ou le mail de l’utilisateur qui a créer le groupe
  - Une sélection m’est proposé
  - Je peux renseigner le code secret du groupe pour valider la demande

# Cas limites

- Pas possible de rejoindre 2 groupes
